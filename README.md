# 鹰眼

### 功能特点

用手机浏览器摄像头识别围棋、象棋盘面和魔方色块，叠到标准盘面或立方体模型上，并给出置信度。第一版只开 1 路本机摄像头、在浏览器内计算；不做文件导入、IP 摄像头、多机对齐、App 和球类。

### 框架特点

站点用 Nuxt 做 Web 壳和页面。视觉引擎放在 `support/` 旁路（如 `support/eye-engine`），不进 Nuxt server。引擎只提供采集、标定、观测总线、插件加载等能力；围棋 / 象棋 / 魔方的模型、算法和交互在独立插件仓，由引擎加载。
